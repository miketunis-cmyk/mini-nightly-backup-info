Mini Nightly Backup

A private desktop utility operated by its account owner. It streams encrypted backups to a dedicated private Google Drive folder and downloads them to check recovery integrity. It is not offered as a public service.

This page describes the utility and its data handling. It does not certify that any particular backup has completed. Only a successful verification receipt identifies a verified recovery point.

The utility requests access only to the specific Drive files used with this application. It does not request access to the owner’s entire Drive.
